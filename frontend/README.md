# E-Tunes Frontend

Next.js-based ear training and transcription UI.

## Quick Start

```bash
npm install
npm run dev
```

## Routes

- `/` — Hub / mode selection
- `/transcribe` — Note and chord transcription
- `/ear-train/interval-id` — Interval identification drills
- `/ear-train/scale-id` — Scale identification drills
- `/scales` — Browse all scales
- `/scales/:id` — Scale detail with playback and visualization
- `/progress` — Session stats and curriculum progress
